# REG-2026-08-25-004 - MEDIA reply was generated but never delivered

## Incident

On 2026-08-25 at 22:03 BRT, the CeoGame Telegram bot received the user's request for the visual proposal and generated a 458-character response containing three `MEDIA:` image directives. No text or image reached the topic. Automatic checkpoint recovery repeated the same pre-network failure.

## Root Cause

The gateway checkpoint sealed the full response envelope, including `MEDIA:` directives. The platform adapter then extracted those directives and attempted to record only the remaining 241-character text as the exact durable obligation. The checkpoint had already been bound before the ledger rejected the text/checkpoint SHA-256 mismatch, leaving a bound checkpoint with no ledger row and suppressing all attachments.

## Prevention

- Reseal the checkpoint to the exact post-extraction text before binding a delivery obligation.
- Persist the resealed text as an inactive recovery artifact under the existing checkpoint CAS.
- Keep stale or already-bound checkpoint rewrites fail-closed.
- Regression-test a response containing a native image attachment and require successful text delivery, image delivery, ledger completion, and matching checkpoint content.
