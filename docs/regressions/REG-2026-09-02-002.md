# REG-2026-09-02-002: Node rejected the dev-sandbox MITM certificates

## Incident

Install & Update E2E run 33687295780 passed every `hermes update` leg but failed all five installer re-run legs at the root Node dependency install.

## Evidence

- Legacy installers from all sampled tags logged an npm failure and continued.
- The current installer correctly treats that failure as fatal, so every re-run stopped at `npm install failed or timed out`.
- The fake-internet proxy logged repeated TLS EOFs during npm access.
- The proxy signs intercepted host certificates with `ca.pem`, while the sandbox exported `NODE_EXTRA_CA_CERTS=real-ca.pem`.

## Root cause

Node trusted the proxy's upstream CA bundle instead of the sandbox CA that signs the certificate presented to Node. Other clients already used the correct sandbox CA.

## Prevention

Keep `NODE_EXTRA_CA_CERTS` aligned with `CURL_CA_BUNDLE`, `SSL_CERT_FILE`, and `GIT_SSL_CAINFO` in the isolated sandbox. The existing real installer E2E is the behavior gate.

## Readiness ceiling

Validated-local requires a passing installer E2E on the exact feature commit. This record does not authorize merge or release.
